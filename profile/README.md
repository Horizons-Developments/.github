## ⁉️ FAQs

**What languages and systems do we use?**

> We primarily use HTML, CSS, JavaScript and Svelte - as a fullstack framework, we're using SvelteKit and BullMQ incl. Redis for queue and worker systems.

**What kinds of projects do we build?**

> We mostly build websites, dashboards, and other web applications. We don’t currently build mobile apps, but we may start doing so after a few successful projects.

**Can we create projects for other people?**

> Currently, we don't build projects for third persons, but feel free to contact us anyways, so we can find a solution for your concern.

**Can I work at Horizons Developments?**

> No, unfortunately that’s not possible. Since we are currently not an official company but more a private hobby project, we do not offer paid positions. Nevertheless, you are of course welcome to volunteer to help with our projects - either open an issue on GitHub or contact us via the methods below to get started.

**Other questions?**

> We’ve got the answers! Feel free to contact us - we’re happy to help you out.
